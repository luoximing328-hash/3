# 法影随行 (Legal Shadow)

## 项目简介

**法影随行**是一个沉浸式法律文化社区与AI智慧助诉平台，致力于让法律不再高冷，让维权触手可及。

**Slogan**: 看得懂的法律故事，用得上的维权武器

## 核心功能

### 首页 🏠
- **成功案例推送**: 展示平台帮助用户成功维权的真实案例
- **法律援助消息**: 发布紧急法律援助信息、免费咨询活动等
- **红色案例警示**: 典型案例分析，帮助用户避免常见法律陷阱
- **快速入口**: 快速访问各个功能模块

### 1. 法影剧场 🎭
- 真实案例漫改，将法律文书转化为有趣的漫画
- 弹幕互动功能
- 分类浏览（合同纠纷、劳动争议、财产纠纷、消费维权）
- 阅读获得法力值奖励

### 2. 法庭直通车 ⚖️
- **诉前模拟**: 选择真实场景，AI扮演法官或对方律师，进行模拟庭审
- **法理要件速记**: 通过法律知识卡牌闯关，赚取法力值
- 胜诉率预测和庭审表现评分

### 3. 逻辑罗盘 🧭
- 五维拆解裁判文书（起因、争执点、法官看点、判决结果、维权启示）
- 可视化图谱展示
- 案例搜索和分析

### 4. 智慧助诉中心 🛠️
- AI智能法律咨询
- 法律文书生成（起诉状、答辩状等）
- 证据清单整理
- 诉前风险评估
- 积分兑换和增值服务

### 5. 志愿者中心 👥
- **资质认证**: 法学生可以申请成为志愿者，需要提供学校、专业、学号等信息
- **任务系统**: 认证后可以接受审核法律文书、整理证据清单等任务
- **服务时长认证**: 获得官方认证的志愿服务时长
- **证书下载**: 可以下载志愿服务证书

## 积分系统

### 获取法力值
- 📖 阅读漫画：+10 法力值
- 🎮 完成模拟：+20 法力值
- 🃏 答对题目：+5 法力值
- 📅 每日签到：+15 法力值

### 法力值用途
- 兑换人工复核服务（法学生志愿者）
- 解锁深度AI报告
- 使用增值服务

- LocalStorage (本地数据存储)

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器运行（推荐）：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js
   npx http-server
   ```
3. 访问 `http://localhost:8000`

## 设计理念

### 色彩方案
- **主色**: 深海蓝 (#1a365d) - 代表法律、理性、严肃
- **辅助色**: 活力橙 (#ff6b35) - 代表Z世代、警示、创新

- 现代化、简洁的设计

- 拒绝传统的法徽、天平堆砌
- 使用线条艺术表现逻辑连接
- 二次元/手绘插画风格

3. **增值服务**: 
   - 单项服务：¥9.9
   - 综合服务：¥19.9
4. **志愿者体系**: 法学生提供志愿服务，获得时长认证
